# Medizininformatik-Initiative – Kerndatensatz – Meta

The **Meta** module of the MII core data set (Kerndatensatz) describes aspects of
FHIR profiling that apply across all KDS modules: the cross-module
SearchParameters, the DIZ-Standorte CodeSystem, the licence extension and the
shared conventions. Package: `de.medizininformatikinitiative.kerndatensatz.meta`.

- **Current publication:** https://medizininformatik-initiative.github.io/kerndatensatz-meta/
- **Ballot 2027.0.0-ballot:** https://medizininformatik-initiative.github.io/kerndatensatz-meta/2027.0.0-ballot/
- **Development preview (`dev`):** https://medizininformatik-initiative.github.io/kerndatensatz-meta/branches/dev/
- **Packages on Simplifier** (mirrored while package releases are still provided there):
  https://simplifier.net/packages/de.medizininformatikinitiative.kerndatensatz.meta
