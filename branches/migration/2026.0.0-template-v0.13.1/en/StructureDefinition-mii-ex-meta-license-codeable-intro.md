This extension can be used to provide machine-processable licence information
about the artifact described by a resource. It is an R4-compatible version of
the FHIR for FAIR R4B IG
[Licence Terms as CodeableConcept extension](https://hl7.org/fhir/uv/fhir-for-fair/STU1/StructureDefinition-licenceCodeable.html).
