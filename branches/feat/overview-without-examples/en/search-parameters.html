Search Parameters

  • Active search parameters
  • Retired search parameters

The Meta module defines the search parameters that are shared across the modules of the MII core data set. The table lists every active search parameter, ordered by the resource type it applies to.

  • Code is the name used in a search request and links to the full definition.
  • Expression is the FHIRPath expression the server indexes.

Example queries are documented in the CapabilityStatement: each one is run in CI against a FHIR server loaded with the MII test data. A search parameter without an example has no test yet.

To load all search parameters into a FHIR server, use the collection Bundle or the transaction Bundle.
