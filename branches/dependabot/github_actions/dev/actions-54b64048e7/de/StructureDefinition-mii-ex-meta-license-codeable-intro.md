Lizenzinformationen über das von einer Ressource beschriebene Artefakt
bereitzustellen. Sie ist eine R4-kompatible Version der FHIR for FAIR R4B IG
[Licence Terms as CodeableConcept-Extension](https://hl7.org/fhir/uv/fhir-for-fair/STU1/StructureDefinition-licenceCodeable.html).
