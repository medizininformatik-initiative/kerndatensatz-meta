> **Deprecated — do not use**
>
> The MII EX Meta License Codeable extension is deprecated and SHOULD NOT
> be used. The
> [CRMI License Extension](https://hl7.org/fhir/uv/crmi/en/StructureDefinition-crmi-license.html)
> SHOULD be used instead.
{: .ig-highlight .ig-highlight-orange}

This extension was introduced to provide machine-processable licence
information about the artifact described by a resource. It is an R4-compatible
version of the FHIR for FAIR R4B IG
[Licence Terms as CodeableConcept extension](https://hl7.org/fhir/uv/fhir-for-fair/STU1/StructureDefinition-licenceCodeable.html).
