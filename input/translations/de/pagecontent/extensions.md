Das Meta-Modul definiert eine Extension:

* [MII EX Meta License Codeable](StructureDefinition-mii-ex-meta-license-codeable.html)
  stellt maschinenverarbeitbare Lizenzinformationen für Artefakte bereit. Sie
  ist veraltet (deprecated): Neue Artefakte verwenden die CRMI-Extension
  [`crmi-license`](https://hl7.org/fhir/uv/crmi/STU2/StructureDefinition-crmi-license.html);
  siehe [Modulkonventionen](conventions.html#lizenzierung).
