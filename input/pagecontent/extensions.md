The Meta module defines one extension:

* [MII EX Meta License Codeable](StructureDefinition-mii-ex-meta-license-codeable.html)
  provides machine-processable licence information for artifacts. It is
  deprecated: new artifacts use the CRMI extension
  [`crmi-license`](https://hl7.org/fhir/uv/crmi/STU2/StructureDefinition-crmi-license.html);
  see [Module Conventions](conventions.html#licensing).
